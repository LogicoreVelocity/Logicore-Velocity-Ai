# Simple Deployment

This is a static React/Vite app.

## Vercel / Netlify / Azure Static Web Apps

Use:

```text
Build command: npm run build
Output folder: dist
```

## Important data warning

The app has no backend. A public deployment does not mean data is shared to a server; records remain in each user's browser vault. However, each user is responsible for exporting backups and protecting their device/browser profile.

Do not ask users to enter official sensitive employee records until a protected backend and privacy policy are connected.
